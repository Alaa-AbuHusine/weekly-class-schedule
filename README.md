# نظام الجدول المدرسي الذكي 🏫
### مدرسة مخيم الزعتري الأساسية الثانية للبنين
**العام الدراسي 2025 / 2026 — الدوام المسائي**

تطبيق ويب متكامل وتفاعلي لإدارة وعرض وطباعة البرنامج الأسبوعي لتوزيع الحصص المدرسية لمدرسة مخيم الزعتري الأساسية الثانية للبنين، مفروز حسب الأيام وحسب المعلمين ومجهز للطباعة الرسمية الفورية على ورق مقاس A4.

---

## 🌟 الميزات الرئيسية للنظام

1. **فصل الجدول الدراسي لكل يوم بشكل مستقل**:
   - تبويبات سريعة للتنقل بين الأيام: (الأحد، الإثنين، الثلاثاء، الأربعاء، الخميس).
   - إمكانية استعراض "الجدول الأسبوعي الكامل" لجميع الأيام دفعة واحدة.
   - تحديد تلقائي ليوم الدوام الحالي وتظليله بشارة ذكية.

2. **طباعة رسمية فاخرة مقاس A4 Landscape**:
   - زر `🖨️ طباعة جدول اليوم` المباشر: يطبع جدول اليوم المعروض فوراً.
   - ترويسة وزارية رسمية معتمدة (المملكة الأردنية الهاشمية - وزارة التربية والتعليم - مديرية التربية والتعليم).
   - تذييل التواقيع الرسمي (مسؤول برمجة الجدول، خاتم المدرسة، مدير المدرسة).
   - تحصين التنسيق بحيث تطبع الورقة بيضاء نقية ومنسقة رسمياً حتى لو كان وضع الشاشة داكناً.

3. **طباعة جدول منفصل لأي معلم**:
   - زر مخصص `👨‍🏫 طباعة جدول معلم` يفتح نافذة لاختيار المعلم.
   - عرض فوري للحصص الأسبوعية، والمواد والصفوف المسندة إليه، وجدول أسبوعي مخصص له.
   - زر طباعة مخصص يخرج جدول المعلم فقط لتسليمه إياه مباشرة.

4. **نظام كشف تعارض الحصص والمعلمين (Conflict Detection)**:
   - فحص آلي دقيق لكافة الحصص والشعب لاكتشاف أي ازدواجية أو تكليف معلم بشعبتين في نفس الحصة.
   - زر إشعار لحظي في شريط الأدوات يوضح حالة الجدول (`⚠️ يوجد تعارض` أو `✅ لا توجد تعارضات`).
   - نافذة مفصلة توضح الحصة واليوم والصفوف المتعارضة مع زر مباشر `✏️ حل وتعديل`.
   - كشف لحظي مباشر أثناء تعديل أي حصة يدوياً ينبه المستخدم قبل الحفظ.

5. **توقيت الدوام المسائي المعتمد (مدة الحصة 35 دقيقة)**:
   - **الحصة 1**: 12:30 - 01:05
   - **الحصة 2**: 01:05 - 01:40
   - **الحصة 3**: 01:40 - 02:15
   - **الحصة 4**: 02:15 - 02:50
   - **الحصة 5**: 02:50 - 03:25
   - **الحصة 6**: 03:25 - 04:00
   - **الحصة 7**: 04:00 - 04:35

6. **أدوات تفاعلية متقدمة**:
   - **البحث الحي الفوري**: تظليل متحرك عند البحث عن أي مادة، معلم، أو صف.
   - **تصفية الصفوف والشعب**: استعراض جدول صف واحد على حدة.
   - **تصفية المعلمين**: استعراض جدول معلم محدد عبر الأسبوع مع حصص الفراغ.
   - **نمط البطاقات (Cards View)**: عرض جدول الحصص على شكل بطاقات منفصلة لكل شعبة.
   - **تعديل الحصص يدوياً**: إمكانية تعديل أي حصة وحفظ التغييرات في التخزين المحلي (LocalStorage).
   - **الوضع الليلي والنهاري (Dark / Light Mode)**: تصميم مريح للعين مع ألوان عالية التباين وخط عربي حديث (Cairo).

## 🚀 كيفية التشغيل والرفع على الإنترنت

### 1. التشغيل المحلي (على جهازك مباشرة):
- لا يتطلب المشروع أي بيئة تشغيل خاصة (No Node.js or Build step required).
- يكفي النقر المزدوج على ملف `index.html` ليفتح في أي متصفح (Chrome, Edge, Firefox, Safari).
- أو عبر خادم ويب محلي:
  ```bash
  python -m http.server 8080
  ```
  ثم فتح الرابط: `http://localhost:8080`

### 2. الرفع إلى GitHub وربطه بـ GitHub Pages (مجاناً بضغطة زر):
1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً باسم `Zattari-School-Timetable`).
2. افتح موجه الأوامر في مجلد المشروع ونفذ:
   ```bash
   git remote add origin https://github.com/USERNAME/Zattari-School-Timetable.git
   git branch -M main
   git push -u origin main
   ```
3. من صفحة المستودع على GitHub:
   - اذهب إلى **Settings** > **Pages**.
   - تحت **Branch**، اختر `main` واضغط **Save**.
   - سيصبح الموقع متاحاً على الإنترنت برابط عام مجاني يمكن مشاركته مع المعلمين والإدارة فوراً!
